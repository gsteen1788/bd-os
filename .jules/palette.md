## 2024-03-15 - [Add missing ARIA labels to inline form controls]
**Learning:** Found several inline inputs and select dropdowns (e.g., in AdminTaskBar and OpportunityBoard) that lacked textual labels, relying entirely on visual context or placeholders. Placeholders are insufficient for screen readers. Also found inputs relying on implicit label wrapping instead of explicit `id`/`htmlFor` linking which is not fully reliable.
**Action:** Always provide `aria-label` attributes to form elements that lack a visible `<label>`. When using `<label>`, prefer explicit association (`htmlFor` mapped to `id`) over implicit nesting to ensure robust screen reader support.
